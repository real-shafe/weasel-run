# Weasel Run

An endless one-button platformer. A weasel in a red bandana runs through four procedurally generated biomes, bops beetles and grabs coins.

**Play:** https://weasel-run.shafe.dev

- Jump and double jump, with a gold sparkle trail while the double jump is still available
- Critters to bop, plus magnet, coin frenzy and bubble shield power-ups
- A "Best" flag marks your farthest run

**Controls:** tap, click or press Space to jump.

Single self-contained `public/index.html`.

## Deploy

Served by a Cloudflare Worker with static assets (`wrangler.jsonc`). Deploy with:

```bash
npx wrangler deploy
```
